Covers curriculum topics 2 to 4: AI deployment architecture, cloud deployment and hybrid deployment. Most enterprises end up hybrid: a cloud model provider for reasoning, with sensitive data, retrieval indexes and tool connections kept inside their own environment. Questions leaders should ask: where is data processed and stored, is it used to train the provider's models, and which region does it sit in? For Indian organisations, check DPDP cross-border transfer rules and sector rules such as RBI's requirement that payment system data be stored in India. In a cloud deployment the provider secures the platform, but identities, permissions, prompts, tools and data access remain your responsibility.
