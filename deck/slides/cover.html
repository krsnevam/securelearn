Governing, trusting, defending and operating AI that acts on its own

Welcome everyone. The first half of the program covered how agentic AI systems are built. This half is about what leaders must do once those systems are live: govern them, decide how far to trust them, understand how they are attacked, and run them safely. Set the expectation that this is a decision-making session, not a coding session.
