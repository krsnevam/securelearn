Module 11 · When agents act

Legitimate tools, illegitimate outcomes

Tool abuse

An approved tool is used for a harmful purpose.

A send-email tool used to leak data

Permission escalation

A junior user reaches senior actions through the agent.

Intern asks agent to approve a vendor

Runaway execution

One bad decision repeated at machine speed.

A loop that deletes or emails thousands

Core controls: least privilege per tool, rate limits, and human approval for anything irreversible.

These three risks share a root cause: the agent has more capability than the task needs. Tool abuse needs no software bug; the tool works exactly as designed. Permission escalation is the "confused deputy" problem: the agent has rights the user does not. Runaway execution is about speed: a human mistake affects one record, an agent mistake can affect thousands before anyone notices.
