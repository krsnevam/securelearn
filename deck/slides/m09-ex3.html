Architecture Review Workshop

3 of 10

Exercise 3 from the curriculum, based on the program's MCP-enabled Risk Advisory Assistant use case. Strong teams will find: agents sharing context can pass one agent's untrusted input into another agent's trusted workflow; shared service credentials on MCP servers create a confused-deputy risk; regulatory repositories may be updated from outside sources without review; and approval processes may be bypassed when an agent can call the tool that records approvals. Recommended mitigations: per-agent identities and scoped tokens, a context boundary between agents (data passed as data, never as instructions), an approved MCP server registry with pinned versions, and human sign-off that the agent cannot perform itself.
