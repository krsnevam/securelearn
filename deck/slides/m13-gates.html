Module 13 · Governance checkpoints

Five gates from idea to ongoing operation

Gate 0

Idea

Use case approved and risk tier set

Gate 1

Design

Architecture and threat review passed

Gate 2

Pre-launch

Security tests and evaluations passed

Gate 3

Go-live

Readiness assessed; owner signs

Ongoing

Review

Re-approval cycle set by risk tier

Scale the gates to the risk tier: low-risk tools pass gates 0 to 3 in days; high-risk agents need the full board.

Governance checkpoints fail when they are the same weight for every project, because teams learn to route around them. Tiering is the answer: an internal summarisation tool should not wait for the same board as an agent that moves money. Suggested ongoing review cycle: quarterly for high-risk systems, annually for low-risk ones.
