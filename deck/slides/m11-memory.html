Module 11 · Memory & identity attacks

The quiet attacks that persist

Memory poisoning

A false “fact” planted once is recalled in every future session.

Agent manipulation

Goals are nudged gradually until the agent works for someone else.

Agent impersonation

A rogue agent or service poses as a trusted one in a multi-agent flow.

Token misuse

Stolen or over-broad API keys let attackers act as the agent.

These attacks matter because they are slow and durable. Memory poisoning survives restarts. Agent impersonation and token misuse are the AI-specific identity concerns: agents hold keys and tokens that often live longer and reach further than any human login. Controls include memory review and expiry, signed agent identities, and short-lived scoped tokens.
