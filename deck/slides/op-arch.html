OPENING CHALLENGE

Project NEXUS · fail first, then learn

Present this neutrally, as the vendor would. Do not point at any weakness. Every flaw that causes the failure is visible on this slide: untrusted inputs (customer emails, vendor PDFs) flow into an agent that has payment and core-banking write tools; one admin service account; a guardrail that is only a prompt; an audit log written by the agent itself; a SharePoint index of 40,000 documents with no mention of permissions; an auto-updating open-source MCP server; and a fixed ₹5 lakh approval threshold shown on a screen the agent controls. If participants ask questions, answer only from what is on the slide: "the vendor says it is enterprise-grade".
