Module 12 · Secure retrieval architecture

Six controls for a secure RAG platform

Source vetting

Only approved sources, each with an owner, enter the index

Secure indexing

Tag sensitivity; strip secrets and personal data first

Permission-aware

Access rights checked at the moment of retrieval

Content sanitizing

Hidden text and embedded instructions removed

Provenance

Every answer cites its source, so errors can be traced

Output filtering

Data-loss checks on answers before users see them
