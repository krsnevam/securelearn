Controls that work while the agent works

Runtime controls

  • Input and output filtering
  • Tool calls authorised at the gateway
  • Rate and spend limits per agent
  • Sandboxed execution for any code
  • Secrets kept out of prompts
  • Session isolation between users

Secure Productization & Lifecycle

7 of 10

Covers curriculum topics 5, 8 and 9: runtime security, human approval gates and runtime controls. Runtime controls are the production version of the policy engine from Module 8. The approval gate table is a starting template; each organisation sets its own thresholds by risk tier. Two warnings for leaders: approval fatigue (if humans approve hundreds of actions a day, the gate becomes a rubber stamp, so keep gates for genuinely high-impact actions) and gate bypass (the agent must not be able to call the tool that records the approval).
