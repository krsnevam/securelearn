OPENING CHALLENGE

Project NEXUS · fail first, then learn

This running group assignment gives the program a single storyline. Allow about 20 minutes at the end of each module for the group deliverable; one page or one diagram is enough. Groups keep a NEXUS folder (a flipchart wall or a shared document) and add to it each module. Every module also opens with a "fail first" trap question tied to NEXUS, so participants feel the problem before they learn the fix. At the capstone, each group presents NEXUS v2 to a mock board, and the original Exhibit A is shown alongside it.
