Module 10 · AI trust architecture

Six things an AI system must decide to trust

Identity

Is this really the user or agent it claims to be?

Context

Can we trust where this content came from?

Tool

Is this tool what it says, and unchanged since approval?

Agent

Is this other agent allowed to instruct ours?

Data

Is it accurate, current and permitted for this use?

Supply chain

Do we know where models, plugins and libraries came from?

Enterprise Trust Architecture

Traditional security focuses mostly on identity and data. Agentic systems add context, tools and other agents as things that must be trusted, and those are where most new attacks land. Ask the room which of the six their current controls cover; most will say identity and data only.
