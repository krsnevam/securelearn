RAG & MCP Security

6 of 10

MCP, the Model Context Protocol, is often described as a universal plug for AI: one standard way to connect agents to tools, data and systems. That convenience is exactly the risk; anyone can publish an MCP server, and installing one is as easy as adding a browser extension. Tool poisoning and rug pulls have both been demonstrated by security researchers. OWASP now maintains a dedicated MCP Top 10 for this layer.
