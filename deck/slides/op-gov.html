This is the trap. Every item is true, and each is what a mature governance function would ask for. None of them tests the architecture on the previous slide. ISO 42001 certifies the vendor's management system, not Meridian's configuration; the penetration test (we reveal later) covered the web application only; the bias test covered the loan model, not the agents' actions; human approval exists but can be bypassed. Leave this slide on screen while groups work. If a group asks for more information, say: "The vendor says the pack is complete."
