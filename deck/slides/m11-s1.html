Real case · Jul 2025

A wiper prompt in an official extension

What happened

An attacker got a malicious prompt merged into Amazon Q Developer’s official VS Code extension, telling its AI agent to wipe local files and cloud resources. The tampered version shipped before AWS pulled it; AWS said no customer resources were affected.

Your situation: 400 of your developers use AI coding agents that can reach terminals and cloud credentials.

Your call · 15 min

  1. Who reviews prompts and agent instructions like code?
  2. What can an agent on a developer laptop reach today?
  3. How fast could we roll back a bad extension?

Source: AWS security bulletin and public reporting, July 2025

MODULE 11

Attack Surface & Risk Landscape

5 of 10

Concept tested: tool abuse and supply chain; natural-language instructions are now executable. Model answer. 1) Prompts, agent rules and skill files go through the same code review and approval as source code, with two reviewers for anything shipped to many users. 2) Usually far too much: local files, cloud command-line credentials, browser sessions. Run coding agents with scoped, short-lived credentials and without production access. 3) Maintain an approved list of AI extensions with pinned versions, pushed by device management so you can roll back centrally. Leadership point: in agentic systems, "a prompt" can delete infrastructure. Treat it like code.
